# Datheon Data Analytics and Power BI Internship

Projects completed for the Datheon Data Analytics and Power BI Internship program. Each project folder has its own README with details.

| Task | Project | Tools | Folder |
|---|---|---|---|
| 1 | Superstore Sales Analysis | Python | [Superstore_Analysis](Superstore_Analysis) |
| 2 | Executive Sales & Profit Dashboard | Power BI, DAX | [PowerBI_Dashboard](PowerBI_Dashboard) |
| 3 | Customer Cohort & Churn Analytics | Power BI, Power Query, DAX | [Churn_Analysis](Churn_Analysis) |
| 4 | Corporate Financial & Margin Dashboard | Power BI, DAX | [Financial_Dashboard](Financial_Dashboard) |

## Highlights
- **Task 1:** Discounts above 20% turn profit negative (lines at 30%+ lost $135K); Furniture earns only a 2.5% margin; sales peak in Q4.
- **Task 2:** West is the most profitable region ($108K); Tables, Bookcases and Supplies lose money.
- **Task 3:** 26.5% overall churn; month-to-month customers churn 42.7%; Fiber optic without tech support churns 49.4%.
- **Task 4:** 14.2% gross margin, with scenario sliders and a budget variance analysis (budget assumed).

## How to open
Open the `.pbix` files in Power BI Desktop. Each folder also has a PDF export and its own README.
